# TaskFlow

A modern and responsive task management application built with HTML, CSS, and JavaScript.

TaskFlow helps users organize daily tasks through an elegant dark-themed interface featuring task priorities, categories, progress tracking, and filtering options.

## Preview

TaskFlow provides:

- Modern dark UI
- Task creation and management
- Priority-based organization
- Category-based classification
- Progress tracking dashboard
- Responsive design for desktop and mobile

---

## Features

### Task Creation
Create new tasks with:

- Task title
- Priority level
  - High
  - Medium
  - Low
- Category selection
  - Personal
  - Work
  - Health
  - Learning

### Task Completion

- Mark tasks as completed
- Completed tasks are visually distinguished with a strikethrough effect
- Automatic progress updates

### Task Deletion

- Remove unwanted tasks instantly
- Clear all completed tasks with one click

### Filtering System

Filter tasks by:

- All Tasks
- Active Tasks
- Completed Tasks
- High Priority
- Medium Priority
- Low Priority

### Progress Tracking

The application automatically displays:

- Active tasks count
- Completed tasks count
- Progress percentage bar

### User Experience

- Smooth animations
- Interactive buttons
- Responsive layout
- Modern typography
- Gradient visual effects

## How to Run

1. Download the project files.
2. Open `todo-list.html` in any modern web browser.
3. Start managing your tasks.

No installation or external setup is required.

---

## Application Workflow

1. Enter a task.
2. Select priority.
3. Select category.
4. Click **Add Task**.
5. Track progress through statistics and progress bar.
6. Filter tasks based on status or priority.
7. Mark tasks as completed when finished.
