# TaskFlow

A modern and responsive task management application built with HTML, CSS, and JavaScript.

TaskFlow helps users organize daily tasks through an elegant dark-themed interface featuring task priorities, categories, progress tracking, and filtering options.

## Preview

TaskFlow provides:

- Modern dark UI
- Task creation and management
- Priority-based organization
- Category-based classification
- Progress tracking dashboard
- Responsive design for desktop and mobile

---

## Features

### Task Creation
Create new tasks with:

- Task title
- Priority level
  - High
  - Medium
  - Low
- Category selection
  - Personal
  - Work
  - Health
  - Learning

### Task Completion

- Mark tasks as completed
- Completed tasks are visually distinguished with a strikethrough effect
- Automatic progress updates

### Task Deletion

- Remove unwanted tasks instantly
- Clear all completed tasks with one click

### Filtering System

Filter tasks by:

- All Tasks
- Active Tasks
- Completed Tasks
- High Priority
- Medium Priority
- Low Priority

### Progress Tracking

The application automatically displays:

- Active tasks count
- Completed tasks count
- Progress percentage bar

### User Experience

- Smooth animations
- Interactive buttons
- Responsive layout
- Modern typography
- Gradient visual effects
